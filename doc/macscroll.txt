*macscroll.txt*	macOS scroll handler for Neovim

==============================================================================
INTRO							*macscroll*

macscroll.nvim owns trackpad and mouse-wheel scrolling on macOS. The Darwin
handler taps every scrollWheel CGEvent when a known terminal is frontmost and
a Neovim listen socket is live, swallows the event, and RPCs |macscroll.scroll|.

==============================================================================
SETUP							*macscroll-setup*

>lua
	require('macscroll').setup({
	  horiz_step = 6,
	  vert_step = 3,
	  auto_worker = true,
	})
<

Install with lazy.nvim (`lazy = false`, `build = 'make worker'`) or clone into
`pack/*/start/`. See the README and |macscroll-accessibility|.

==============================================================================
ACCESSIBILITY					*macscroll-accessibility*

The Darwin worker taps every scrollWheel CGEvent. macOS delivers that tap
only if **macscroll-worker** is allowed under System Settings → Privacy &
Security → Accessibility.

    1. Build/start the worker (`:MacscrollBuild`, `:MacscrollStart`).
    2. Enable macscroll-worker in Accessibility. If it is missing, add
       `stdpath('data')/macscroll/macscroll-worker` (usually
       ~/.local/share/nvim/macscroll/macscroll-worker).
    3. Restart the worker (`:MacscrollStop` / `:MacscrollStart`). A tap
       that failed at launch does not start when you tick the checkbox.

Grant the worker binary, not nvim or swift. Rebuilding can require
toggling the row again. Without this grant the TTY still filters wheels.
See README and docs/TUTORIAL.md.

==============================================================================
COMMANDS						*macscroll-commands*

:MacscrollBuild		Compile handler/darwin into stdpath('data').
:MacscrollStart		Force-listen and start macscroll-worker.
:MacscrollStop		Close the RPC socket.

==============================================================================
HEALTH							*macscroll-health*

:checkhealth macscroll

Allow Accessibility for macscroll-worker or the session tap cannot see
events. See |macscroll-accessibility|.
